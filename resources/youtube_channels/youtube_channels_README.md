# YouTube Channels

Study material sourced from YouTube channels, structured the same way as `../books/`: one folder per channel, and inside it a `topics/` folder - the same generic unit `books/` uses for chapters, since a channel doesn't have chapters but does have topics (individual videos or video series covering one subject).

Each channel folder is named `<channel_slug>/` and should contain:

- `<channel_slug>_README.md` - what the channel is and how it's being used.
- `topics/` - one folder per topic, following the exact same six-file pattern as a book chapter (`notes.md`, `deeper_dive_notes.md`, `practice_questions.md`, `deeper_dive_questions.md`, `flashcards.md`, `deeper_dive_flashcards.md`, plus the generated `flashcards_data.js`/`flashcards.html`).
