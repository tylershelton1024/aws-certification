# Practice Tests

Quick, chapter-scoped quizzes - built from what you've told me about a chapter, your notes, and general AWS Cloud Practitioner knowledge. These are shorter and more informal than a full mock exam; the goal is a fast check on what's actually sticking after each chapter, not a simulated exam.

Individual quiz questions aren't archived question-by-question - the score and any notable misses get logged in `results_dashboard.md` so we can see trends over time. If we later want full-length mock exams too, that can be added as its own thing without disrupting this.

## Files

- `results_dashboard.md` - a running log of quiz scores by chapter/date, used to spot weak areas (feeds into `progress/progress_tracking.md`).
