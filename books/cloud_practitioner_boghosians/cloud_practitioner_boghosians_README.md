# AWS Certified Cloud Practitioner (Boghosians)

"AWS Certified Cloud Practitioner: Understand AWS Like Never Before with Analogies & Real-World Examples" by Rafi Boghosians. Primary source for CLF-C02 prep - see `resources/resources.md` for how it fits alongside other resources (Neal Davis course, YouTube channels).

Style note: heavily analogy-based (e.g. comparing service models to ordering pizza, a VPC to a house in a gated neighborhood). Good for building intuition; notes here should keep the analogies where they help, but also capture the literal AWS facts and terminology the exam actually tests on, since analogies alone won't cover exam-precise wording.

## Files

- `chapters/` - notes and practice questions, one folder per chapter (see `chapters/chapters_README.md`).
